# Colab and Other Tools Practice Run

## Lab Session Overview
This lab session serves as an introductory practice run for working with Google Colab 
and other collaborative tools used throughout the course. The goal is to build 
familiarity with the environment before diving into more complex assignments.

## What We Covered
- Setting up and navigating Google Colab
- Running basic code cells and markdown in a notebook environment
- Exploring additional tools and integrations used alongside Colab
- Practicing version control fundamentals, including creating a repository and making commits

## Purpose
This session is designed to reduce friction in future labs by ensuring all tools 
are properly configured and that students feel comfortable with the workflow 
before applying it to graded work.

## Notes
- No prior experience with Colab is required
- This is a low-stakes practice environment — experiment freely
- Refer to the course materials for setup guides if needed
